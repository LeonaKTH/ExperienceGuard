# 安全与使用边界

- 服务面向本机单用户演示，绑定 `127.0.0.1`，不是可暴露公网的多租户服务。Host/Origin 检查不替代认证系统。
- 代码与 CI 文本是不可信数据。Agent 只访问审核后冻结的文本，没有 Shell、安装、写入、网络搜索或记忆保存工具。
- API Key 仅从进程环境读取；禁止通过 URL、配置或日志传入。DeepSeek 仅允许官方 HTTPS 端点，拒绝重定向，不自动重试。
- 请求和原始响应在本机保留以便排错；Authorization 不进入这些文件，精确 Key 回显会在持久化前阻止。其他敏感文本依赖启发式脱敏与用户审核，不能保证自动识别所有隐私。
- 用户仓库只读，symlink/junction 不跟随，读取范围和尺寸有上限。Git 读取禁用外部配置、hooks 与可选锁；自动 unittest 仅限自建、校验一致的可信示例副本。
- Memory 是历史证据。成功来源、条件全满足和 schema 兼容才允许 B4 复用，未知前提不推断为真。人工验证声明与独立示例执行分开标记。
- 预算按所配置输入/输出价格上界预留。服务端 Token 报告、价格变化、账户其他调用均可能影响真实账单，客户端无法提供账户级硬限额保证。不要通过删除账本绕过累计控制。

请勿将密钥或含私密代码的日志附在公开 Issue 中。报告安全问题时先提供不含凭证的最小复现；如怀疑真实凭证已泄露，应在对应服务撤销并更换。
